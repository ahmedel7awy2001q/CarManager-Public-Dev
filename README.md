# CarManager

Premium Android vehicle-management application.

## v1.0.0 — Phase 4 consolidated release
This release consolidates the Phase 4 work: vehicle-aware spare-parts discovery and fitment confidence, guided vehicle identity, independently updateable vehicle catalog, editable operational records, improved Egyptian-market price discovery, and the full true-cost / trip-pricing assistant with places search, maps, routing, capacity validation, depreciation and annual costs.

Application identity remains `com.ahmed.carmanager`; database upgrades are non-destructive and preserve existing user data.
