# v0.3.0 Professional Cloud & Design Scope

Primary goals:

1. Add Firebase Authentication with Google and Email/Password.
2. Associate all vehicle data with the authenticated user's UID.
3. Preserve legacy local v0.2.x data and offer one-time ownership claim after sign-in.
4. Add Cloud Firestore synchronization while keeping Room as the offline source of truth.
5. Add a professional account/profile area with sync status and sign-out.
6. Remove redundant vehicle license-number input; plate number remains the durable registration identifier in the primary vehicle form.
7. Refine dashboard, garage, forms, empty states, navigation, typography, spacing and destructive-action placement.
8. Keep permanent signing, applicationId and safe update path unchanged.
