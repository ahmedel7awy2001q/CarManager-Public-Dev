# CarManager v0.4.0 — Product Fusion Progress

آخر تحديث: 09/09/2026

## تم تنفيذه

- الواجهة الرئيسية الاحترافية والتنقل الرئيسي: الرئيسية، الصيانة، الإضافة السريعة، التقارير، المزيد.
- الحسابات وعزل بيانات كل مستخدم مع Firebase Auth/Firestore والعمل Local-first.
- مزامنة ونسخة احتياطية سحابية على مستوى الحساب.
- سجل موحد لتاريخ السيارة.
- مركز حالة السيارة والتحليلات المبنية على البيانات المسجلة فعليًا.
- تقارير الفترات وتوزيع التكلفة وتكلفة الكيلومتر ومتوسط الاستهلاك.
- تصدير PDF وCSV/Excel محليًا.
- خزنة مستندات السيارة مع صورة/PDF اختياري.
- فحص السيارة وتحويل الملاحظات المهمة إلى سجل أعطال.
- مرفقات للصيانة والمصاريف مع ربط الملف بالسجل نفسه.
- عزل قراءة/كتابة المرفقات على السيارة التابعة للحساب المسجل.
- زر الرجوع يعيد للشاشة الرئيسية ثم يطلب تأكيدًا قبل إغلاق التطبيق.

## جارٍ التحقق منه قبل نسخة التجربة

- إكمال CI بعد إصلاح أخطاء التجميع الأخيرة في تصدير PDF ومستودع المرفقات.
- تشغيل اختبارات الوحدة.
- إنشاء APK Release بنفس مفتاح التوقيع الدائم والتحقق من الشهادة.

## الخطوات التالية

1. توسيع المرفقات إلى الوقود والقطع والأعطال عند الحاجة.
2. تحسين نموذج تسجيل الصيانة ليشمل رقم الفاتورة والضمان والفني بدون تعقيد الواجهة.
3. حفظ نتائج الفحص كتاريخ قابل للمراجعة وليس كمستند مختصر فقط.
4. إضافة حماية اختيارية PIN/Biometrics للمستندات الحساسة.
5. مراجعة UX نهائية للشاشات الرئيسية على الهاتف قبل تثبيت v0.4.0 كنسخة مستقرة.

قاعدة الإصدار: لا يتم إرسال APK للمستخدم قبل نجاح Debug + Unit Tests + Release Signing + apksigner verification بالكامل.
