# UX review notes from v0.2.0 device screenshots

Observed improvements for v0.3.0:

- Dashboard must always resolve the primary vehicle when one exists.
- Primary dashboard card should be the visual anchor and expose only frequent actions.
- Garage cards should move archive/sell into an overflow menu; edit and set-primary remain accessible.
- Vehicle form should be grouped into compact sections instead of a long administrative form.
- Remove redundant `licenseNumber` field from primary create/edit flows; retain plate number.
- More hub should be denser and categorized instead of oversized repeated cards.
- Empty states must provide a direct recovery action.
- Bottom navigation height, icon sizing and typography should be normalized.
- Use a single coherent surface palette instead of mixed blue/purple containers.
- Numeric values should use a dedicated display hierarchy and consistent localized formatting.
- Backup sheets must respect navigation/system insets.
- All RTL arrows, padding and menus must be audited.
